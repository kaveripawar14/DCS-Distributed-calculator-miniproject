# Distributed Calculator Web Service

## Project Overview
The Distributed Calculator Web Service is a web-based application developed using Python and Flask. It follows a client-server architecture in which users enter numbers and select arithmetic operations through a web browser.

## Objectives
- To understand client-server communication.
- To implement a web service using Flask.
- To perform addition, subtraction, multiplication and division.
- To handle invalid operations such as division by zero.
- To understand the role of distributed web applications.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Web Browser

## Features
- User-friendly calculator interface
- Four arithmetic operations
- Division-by-zero error handling
- Recent calculation history

## How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run the application using `python app.py`.
4. Open http://127.0.0.1:5000 in a browser.

## Sustainable Development Goal
**SDG 4 – Quality Education:** This project can help students practise basic arithmetic and understand client-server web applications.

## Conclusion
The project demonstrates a basic client-server web service using Flask and provides practical experience with web application development and distributed computing concepts.
